启动 PowerUI.exe。左键点击托盘图标打开面板，右键菜单或设置中可退出。
仅需此 EXE，无需旁置配置或 DLL。托盘右键“关于 PowerUI”或 --about 可查看内嵌说明与许可。
开机启动默认关闭，可在设置中开启。无需厂商软件常驻，无需管理员权限。

当前实测：雷柏 VT3S MAX，接收器 24AE:1421。
罗技 MX Master 3S 通过 Logi Bolt 046D:C548 和蓝牙 046D:B034 均已实测读取电量。
VT3 MAX 24AE:1417 未实测，不承诺其他型号。P5 PLUS 底座不在读取范围。
VGN S99 2.4G 接收器 320F:5088 已实机读取电量；不支持其蓝牙/有线模式或同 VID/PID 的其他型号。
可同时展示一只自动选中的受支持鼠标与一把 S99。多鼠标接口并存时优先有效响应，多个有响应时保持当前设备。
USB/蓝牙设备变化后自动重查；没有有效鼠标状态时每10秒重试；仅关闭鼠标且没有设备事件时在下次电量查询切换。
雷柏接收器可见但报告无效时显示型号和等待电量，不沿用断联罗技的显示。不按最近鼠标位移切换。
多个 S99 接收器仍不自动选择；不影响鼠标监控。
设置中“托盘显示”可选分别显示、仅鼠标、仅键盘；单图标模式仍后台监控两类设备。
右键菜单可查看另一类设备。两类设备独立设置低电量阈值。
托盘外圈按比例显示电量，中心区分鼠标和键盘，随任务栏主题切换深浅色图形。
>40% 绿色、21%-40% 黄色、<=20% 红色；无新读数时为灰色虚线环。
悬停或打开面板查看精确百分比及充电状态。环颜色不随提醒阈值改变。

鼠标和键盘可在各自设置中独立选择查询间隔：1分钟、5分钟、10分钟、半小时，默认1分钟，自动保存。
启动时立即查询，手动刷新不受间隔限制。读数有效期为查询间隔加1分钟，且至少5分钟。
过期或刷新未取得有效状态时在面板显示 --，托盘为灰色虚线环。充电状态不冒充新的百分比。
默认 <=20% 提醒一次，只有新读数 >25% 才重新允许下一轮提醒。
提醒阈值可选 5%-90%，恢复线随之设为阈值+5个百分点。

把便携文件放在可写目录。程序旁的 PowerUI.state.xml 保存鼠标设置、电量及全局托盘模式，
PowerUI.keyboard.state.xml 独立保存键盘设置、电量及提醒状态；两者均保留 .bak。
移动文件夹时保留它们；启用过开机启动的，移动后需重新开启。
不要为解决目录写权限而使用管理员身份运行。

需要 Windows 自带 .NET Framework 4.8 或更新版本，不需要额外安装 .NET SDK。
本程序为未签名开发版。低电量通知送达、真实充电/睡眠/拔插、开机登录仍待实机验收。

诊断工具不随单文件版分发，可从源码运行 build.ps1 -IncludeProbe 单独构建。
PowerUI.Probe.exe：无参数只读枚举；--listen 最多被动等候8秒，输出真实电量。
--mouse 使用应用的自动鼠标选择逻辑，显示所选设备、有效状态及电量。
--logitech 只读查询 Bolt 或 MX Master 3S 蓝牙型号和电量，不修改鼠标设置；查询可能让鼠标响应。
--vgn 只枚举；--vgn-battery 只读查询 S99 2.4G 电量，不读取按键或修改设置。
诊断不输出设备路径或序列号。
