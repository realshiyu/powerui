本文件记录当前实现依据，不是通用协议规范，也不保证其他设备或固件适用。仅使用公开设备标识，不记录设备序列号或完整实例路径。

## 原生 Windows 接口

同一接收器的 HID 顶层集合有独立路径。不能把网页 WebHID 的设备聚合方式直接套用到原生 API。

在已验证的 `1421` 接收器上：

| 作用 | Usage Page:Usage | Report ID | 长度（含 ID） |
| --- | --- | --- | --- |
| 电量输入 | `FF00:0002` | 7 | 19 字节 |
| 查询输出 | `FF00:000E` | 6 | 33 字节 |
| 查询 ACK | `FF00:000F` | 8 | 33 字节 |

代码同时检查 VID/PID、usage、report ID 和长度。多个匹配接收器时拒绝猜测对应关系。普通键盘和鼠标输入集合不用于读取电量。

## 百分比解析

原生输入缓冲第一个字节是 report ID。对 report 7：

- 索引 7：状态，`0` 为无效，`1` 为有效电量，`2` 为充电。
- 索引 8：电量字段，仅在状态 `1` 且值在 `0..100` 内时作为新百分比。
- 状态 `2` 只更新充电状态，保留上次百分比及其原始时间，不触发低电量提醒。

WebHID 的 `event.data` 不包含 report ID，因此相应索引是 6、7，不能直接复制偏移。

托盘应用每 60 秒被动监听一次，最多 5 秒。没有新报告时不猜测离线或休眠；旧百分比超过 5 分钟后，托盘显示 `--`。

## 实验性主动查询

只有诊断程序的 `--query` 使用该路径：report 6，无线前缀 `A5`，只读固件命令 `A3 00` 或电量命令 `AA`；随后从对应集合读取 feature report 8。

调查中 ACK 返回过 `0`，尚未验证网页驱动要求的成功值 `1`。没有可信的 feature 响应百分比偏移，不从任意字节猜电量。实际可用路径是被动 input report 7，常规应用不依赖主动握手。

协议资料与权利边界见 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。新增支持必须补充真实设备与固件的验证结果。

## 罗技 MX Master 3S / Logi Bolt

2026-10-22 实机：接收器 `046D:C548`、版本 `0503`，HID++ 长报告集合 `FF00:0002`，输入/输出 report ID `0x11`，长度均为 20 字节。仅打开厂商集合，不读取普通鼠标/键盘输入。

报告头为 `[0x11, 配对槽位, 功能索引, 函数 | software ID 0x0B]`，参数从索引 4 开始。扫描槽位 1..6，通过 ROOT 功能 `0x0000` 的 getFeature 动态发现 `0x0005`（型号）和 `0x1004`（Unified Battery）。型号长度及分段名称用于确认 `MX Master 3S`，不以接收器 PID 推断鼠标型号。

Unified Battery 函数 `0x00` 返回能力，第二参数 bit 1 必须支持百分比；函数 `0x10` 返回状态，参数 0 是百分比（0..100），参数 2 是充电状态（0 放电、1/2 充电、3 完成）。错误或未知状态不作为有效读数。不会将离散电量档位当作精确百分比。

本机动态发现槽位 2、功能索引 `0x08`，成功读取 `95%`、充电状态 `0`。索引不写死。每次刷新重新发现，单次请求最多等待 600ms，并受整体读取预算限制；未完成槽位扫描不返回部分结果。多个接收器或多只匹配鼠标拒绝自动选择。

只发送型号、功能发现、电量能力和状态的只读查询，不写 DPI、按键、滚轮、配对、灯效或固件。与雷柏被动监听不同，Bolt 查询可能让设备响应，不承诺不唤醒。真实充电、睡眠、拔插与多设备拒绝分支尚待实机验证。

## 罗技 MX Master 3S / 蓝牙

2026-10-22 实机确认 `046D:B034`、版本 `0006`，厂商集合 `FF43:0202` 的输入/输出 report ID 均为 `0x11`、长度均为 20 字节。Windows 蓝牙 HID 路径使用 `VID&02046D`，不同于 USB 的 `VID_046D`；路径过滤后仍核对 HID attributes 的 VID/PID 和完整集合描述符，不读取普通鼠标集合。

复用上述 HID++ 型号、功能发现、能力和状态查询，蓝牙直连仅查询设备索引 `0xFF`，不扫描 Bolt 槽位。本机成功查询 `MX Master 3S`、动态功能索引 `0x08`、电量 `95%`、充电状态 `0`。面板连接类型显示为蓝牙，状态仍保存在原有 XML，设备切换时不会沿用另一设备的电量和提醒标记。

蓝牙与 Bolt 同时匹配时沿用拒绝歧义选择策略，不猜测是否为同一只鼠标。仅验证了本机蓝牙查询及面板路径；蓝牙断连重连、睡眠恢复、真实充电转换仍待验证。不将系统缓存的 GATT 电量作为新 HID++ 读数。
